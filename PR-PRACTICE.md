# Pull request practice

This small documentation change is here to practice FreeBuff's GitHub workflow without changing application code.

1. Scan this project and review the changed file.
2. Create a local commit on `freebuf/pr-practice`.
3. Push the branch to the saved GitHub repository.
4. Open a pull request from `freebuf/pr-practice` into `master`.

Review the pull request on GitHub before merging it.
