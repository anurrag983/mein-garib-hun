# FreeBuff Practice Project

This small Python project is a safe place to practice FreeBuff's local scan, review, and Git workflow.

## Current project status

`app.py` has already been fixed: when `people` is zero, `calculate_share` returns `0.0` instead of crashing. Run it with `python3 app.py`; it should print `Each person pays: 0.00` and exit successfully.

## Try a FreeBuff commit

1. In FreeBuff, select this original folder: `/Users/anurag/Documents/FreeBuff-Demo`.
2. Scan the project and review the result. This fixed baseline should not report the old division-by-zero bug.
3. Make a small change to this README, such as adding your name under **Practice change** below.
4. In FreeBuff, prepare the Git review, check the changed-file list, then create a local commit.
5. Push or open a pull request only after connecting a repository you own or have permission to update.

## What to check before committing

In FreeBuff's Git review, confirm that `README.md` appears as a changed file and that the preview includes this section. The commit message should describe the README update; nothing is committed until you choose **Commit locally**.
